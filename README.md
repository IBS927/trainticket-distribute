# trainticket-distribute
別リポジトリにあるtrainticket-ipamに設定ファイルがあり、それを元にコンテナを任意のノードにデプロイする。
それぞれのAPIは以下の通り

・/no_proxy_no_mysql  
データベース以外のサービスをデプロイする  
・/no_proxy_mysql  
データベースをデプロイする  
・/envoy  
サービスとEnvoyプロキシをデプロイして、サイドカーを実現する  
・/envoy_del  
サービスとEnvoyプロキシを削除する  
・/af_packet  
エコーアプリケーションをカーネルリダイレクトでデプロイする用  
・/pf  
エコーアプリケーションをデバイスパススルーでデプロイする用  
・/ld_preload  
NginxやMemcachedをカーネルリダイレクトでデプロイする用  
・/no_proxy_del  
サービスを削除する  
・/snic  
サイドカーのSmartNICをデプロイする用  
・/snic_del    
サイドカーのSmartNIC環境を削除する用  
・/ambient  
中央集権プロキシをデプロイする用  
・/snic_ambient  
中央集権SmartNICをデプロイする用    
・/ambient_del  
中央集権プロキシを削除する用  
・/sidecar  
サイドカーのプロキシとサービスをデプロイする用  
・/pf_preload  
デバイスパススルーのNginxやMemcachedをデプロイする用  
・/pf_lb  
2つのNginxをデバイスパススルーでデプロイする用  
・/multi_preload  
複数のカーネルリダイレクトNginxをデプロイする用  
・/multi_service  
複数のNginxをiptablesでデプロイする用  
・/multi_del  
複数のNginxを削除する用
